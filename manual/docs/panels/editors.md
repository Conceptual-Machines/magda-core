# Editors

The bottom panel displays an editor that auto-switches based on the current selection. Select a MIDI clip and it shows the Piano Roll; select an audio clip and it shows the Waveform Editor, and so on.

| Editor | Shown when you select |
|--------|-----------------------|
| [Piano Roll](piano-roll.md) | A MIDI clip |
| [Drum Grid Editor](drum-grid-editor.md) | A MIDI clip on a track whose instrument is MAGDA's Drum Grid, or is set to **Prefer Drum Grid** (in the track header's or the Plugin Browser's right-click menu) |
| [Waveform Editor](waveform-editor.md) | An audio clip |
| Chord editor | A clip on the [chord track](../chord-track.md) |
| Automation clip editor | An [automation clip](../automation.md#automation-clips) |
| [Track Chain](track-chain.md) | A track or device |

For a MIDI clip, the **Piano Roll / Drum Grid** tabs in the toolbar switch between the two editors.

Double-click a clip to open the bottom panel on it, and double-click again to close it.

## Shared Controls

The Piano Roll, Drum Grid Editor and Waveform Editor share one layout: a toolbar across the top and an icon rail down the left edge.

- The toolbar's right-hand end carries the same controls in each: **Maximise** to fill the window, the clip's **Power** switch, the grid (division, **AUTO** and **SNAP**) and **Loop**, which turns the selected clip's own loop on or off.
- The rail holds each editor's view toggles, such as Fold in the Piano Roll or the spectrogram in the Waveform Editor.
