# First Session

This guide walks you through creating your first project in MAGDA.

## Creating a New Project

1. Launch MAGDA
2. Select **File > New Project**

You choose where the project is kept the first time you save it.

## Adding a Track

Press ++ctrl+t++ (or ++cmd+t++ on macOS) to add a new track, or use **Track > Add Track** from the menu.

## Recording Audio

1. Set up your audio input in **Settings > Audio & MIDI** (++cmd+comma++ on macOS, ++ctrl+comma++ on Windows and Linux). See [Audio & MIDI](../interface/audio-settings.md).
2. Arm a track for recording by clicking its **R** button
3. Press the **Record** button in the transport bar
4. Press ++space++ to stop

## Navigating Between Views

Use the mode buttons in the footer bar at the bottom of the window, or ++f1++, ++f2++ and ++f3++, to switch between views:

- **Live** — Session view with clip launcher
- **Arrange** — Timeline arrangement view
- **Mix** — Full mixer with channel strips

## Saving Your Work

Use ++ctrl+s++ (or ++cmd+s++ on macOS) to save. Use ++ctrl+shift+s++ (or ++cmd+shift+s++) to save as a new file.
