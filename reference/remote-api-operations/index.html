    Remote API Operations¶

    Every operation the Remote API offers, generated from MAGDA's operation registry. The same catalogue is published as an OpenRPC 1.3 document, magda-openrpc.json, for client generators and API tools. A running MAGDA returns the same operations and schemas from system.describe.

    Parameters go by name in params. The types below are a summary: the OpenRPC document carries each parameter's and result's full JSON Schema, including ranges, enums and size limits. Scope is the permission the named client needs. A transport-scoped method is carried out by the WebSocket connection itself rather than the project, and has no MCP tool.

    Any method can also fail with the errors listed at the end of this page.

    Errors¶

    JSON-RPC code error.data.code Meaning
    -32700 — Malformed JSON.
    -32600 invalid_request Invalid JSON-RPC framing or unsupported route.
    -32601 unknown_operation Unknown method.
    -32602 validation_failed params did not satisfy the method's input schema.
    -32603 internal_error Unexpected server failure.
    -32001 not_found A referenced project entity does not exist.
    -32002 conflict State or revision conflicts with the request.
    -32003 timeout The request missed its deadline.
    -32004 cancelled Work was cancelled.
    -32005 — Connection request rate or in-flight limit exceeded.
    -32006 permission_denied The client's grant does not include the method's scope.
